PROJECT DETAILS

模型、扫描面与定位

* 必填项
工位模型毫米单位 · STL / STEP / IGES 等

导入的模型当前坐标直接作为整车坐标，三份数模需预先按装配关系对齐。STL 以外的格式（STEP / IGES / OBJ / PLY 等）会先自动三角化为 STL；PRT、SLDPRT、CATPart 等原生格式请先在 CAD 中导出为 STEP 或 IGES。底座留空时，服务优先使用 input/base.stl 作为底座；该文件不存在时，会生成一块位于主扫描面背后的参考平板作为遮挡基准。

整车主扫描面扫描仪所在侧 / 主面外法向
尚未导入零件

整车轴：X 前−后+，Y 左−、右+，Z 下−上+。自动推荐会统计模型主平整面的面积；推荐结果可随时手动修改。

扫掠模式把相邻视点连成连续扫描带，覆盖率描述的是真正扫过的区域，LS 里用 L 直线 + CNT0 连续走；纯位姿模式是旧版行为，只给孤立位姿，点与点之间的运动不做任何保证。

现场定位点先在 3D 模型上点选，再输入实测坐标
定位点数量 已选 0 / 3
超过该值将拒绝规划

在下方 3D 模型上依次点击零件表面的定位特征；右键或「撤销最后一点」可回退。选点完成后，在模型下方的表格中填写对应的现场坐标。

现场坐标会记在本机浏览器里，下次打开页面时自动回填上一次的输入，确认与本次定位点对应即可；不需要时可点表格上方的「清空现场坐标」。

定位与现场坐标填写完整后，在第 3 个模块「路径规划」中填写 LS 程序名并开始规划。
