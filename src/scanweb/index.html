PATH PLANNING / EXPORT / DELIVERABLES

路径规划

PLANNING

「路径规划最大点数」限制最终 .LS 里的程序点数（每个扫描带算 2 点、每个孤立位姿算 1 点，过渡点另计）。留空表示只按覆盖率目标停止；填写后若达不到覆盖率目标，报告会写明是「点数受限」并给出放弃的覆盖面积。

◆程序名会成为 .LS 与配套 CSV / JSON 的文件名，必须以字母开头，仅含 A–Z、0–9 和下划线，最多 16 字符。
!生成的是笛卡尔路径：扫掠模式的扫描段是连续直线（L + CNT0），行与行之间是「短 L 抬刀 + J 关节运动到预备点 + 短 L 切入」（J 100% CNT100）；纯位姿模式是孤立位姿（J + FINE）。两者都不包含机器人逆解、关节限位和机械臂碰撞验证，关节运动的实际轨迹由控制器决定。导入 ROBOGUIDE 后必须复核 UFRAME、UTOOL、可达性与碰撞。
