# 目标面：拓扑定义

拓扑定义的完整说明：目标面由什么组成、什么被排除，以及为什么所有基于朝向的分面规则在真实数模上都失效。

零件是一块冲压出来的薄铁片，所以按广义的面来说它**只有两个面**——就是它还是平整铁皮时
的两个表面。成型侧壁属于它由哪一面折出来就归哪一面。冲裁（冲孔/落料）出来的剪切断面
**两个面都不属于**，因为它是"切开材料"产生的，不是铁皮的表面。

```
目标 = 原始铁皮的两个面之一
       **含**成型侧壁、含凹腔/凹槽内壁
 减去 = 夹具夹持的区域（不要求测量）
排除 = 剪切断面（冲裁/冲孔边）
排除 = 铁皮的另一面
```

基于朝向的规则在这里**全都行不通**，原因各不相同：`normal_z > 0` 在零件于夹具中倾斜时
立刻失效；二面角分割出的 patch 不等于一个面，因为折痕会把一个面切成好几块平面；用
"与零件自身贯穿轴的夹角阈值"会把成型侧壁切掉，而侧壁属于该面；而"去掉冲裁边后取连通
分量"在真实 CAD 网格上直接失败——各张曲面是分别网格化的，重合顶点从未合并。

有效的方法记录在 [`src/scanplan/sheet_split.py`](../src/scanplan/sheet_split.py)。

## 哪一侧：由操作员指定的主扫描面法向决定

分面算出来的两个集合叫 `upper` / `lower`，只是**几何名**：种子方向（贯穿轴）的符号是任意的，
所以操作员点的那一面在真实工位上完全可能叫 `lower`。因此规划时不再看名字：

- 网页端把界面里选的「整车主扫描面」轴向换算到测量坐标系，传给
  `pipeline.plan(face_axis=...)`；
- `pipeline.facing_face()` 对两个分面各算**带符号投影面积**（`Σ 面积 · (法向 · 轴向)`），
  取大的那一侧 —— 扫描仪看得到的那一侧投影为正，成型侧壁在同一个面内部相互抵消，不会把结果翻过来；
- 判定结果（轴向、两个投影面积、选中哪一侧、被忽略的 `upper/lower` 名字）写进
  `coverage_report.json` 的 `target_face_selection`。

这条规则是 2026-10-29 一台真实工位逼出来的：网页端当时硬编码 `face="upper"`，而那台零件的
1.15 m2 大面恰好被分面叫作 `lower`，于是规划去扫了 113 cm2 散在零件背面的小面片 —— 界面上
橙色（主扫描面）那一整面一个采样点都没有。
